# Security

Report suspected security vulnerabilities in warp-optix privately to NVIDIA's
Product Security Incident Response Team (PSIRT). Please do not disclose them in
public GitHub issues, discussions, or pull requests.

## Reporting a vulnerability

- Web: Follow the instructions on NVIDIA's
  [Report a Security Vulnerability](https://www.nvidia.com/en-us/security/report-vulnerability/) page.
- Email: Contact [psirt@nvidia.com](mailto:psirt@nvidia.com). Encrypt sensitive
  details using [NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Please include:

- The project name (`warp-optix`) and affected version, branch, or commit.
- The vulnerability type, its potential impact, and how it could be exploited.
- Steps to reproduce the issue and a minimal proof of concept, if available.
- Your operating system, GPU model, NVIDIA driver and CUDA Toolkit versions,
  Python version, and versions of `warp-lang`, `pyoptix`, and any relevant
  optional dependencies.
- Whether the issue occurs in the Warp integration, supplemental native bindings,
  path tracer, or a dependency, if known. You can report an issue even if you
  cannot identify the responsible component.

## NVIDIA Product Security

See the [NVIDIA Product Security portal](https://www.nvidia.com/en-us/security/)
for security bulletins, and the
[PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/) for
coordinated disclosure and acknowledgement information.
